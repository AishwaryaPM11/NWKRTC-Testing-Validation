# Feature Checklist for Validation

Use this checklist during the project demonstration and testing. Tick an item only after checking it.

- [ ] Passenger home and navigation
- [ ] FROM/TO search and direction ordering
- [ ] Search validation for missing and identical locations
- [ ] No-results state
- [ ] Live map with no selected bus
- [ ] Live map with stale/missing GPS
- [ ] Live map with fresh GPS data
- [ ] Approximate ETA and distance display
- [ ] Driver login and role profile
- [ ] Driver assigned-trip list
- [ ] Start, delay and complete trip actions
- [ ] Driver GPS permission and location updates
- [ ] Driver issue notification
- [ ] Admin login and role access
- [ ] Admin bus, route, driver and schedule management
- [ ] Admin trip monitor, reports and notifications
- [ ] Firebase database rules checked with authorised and unauthorised test accounts
